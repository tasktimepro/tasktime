# Homepage screenshot workspace

`tasktime-paperplane-studio-2026-09-12.json` is a portable **Import Data** file for
TaskTime Pro (backup format 1.5), built around the fictional Paperplane Studio.
All people, businesses, transactions, and contact details are synthetic;
contact addresses use reserved `.example` domains.

## Import

1. Open the local app in a separate browser profile with cloud storage disconnected.
2. Open **Account → Your Data → Import** and choose the JSON file.
3. Wait for **Backup restored successfully** and the populated Current Data counts.
4. Open Dashboard or Plan & Track.

Import **replaces** the current local workspace, including preferences. Export
any existing data you want to keep first. Keep the screenshot profile separate
from your real Google Drive/Dropbox workspace.

The file selects EUR, light mode, Monday-first weeks, visible totals, and manual
sync (automatic sync, automatic backups, and system notifications disabled).
The saved auto-sync mode is **Sync between devices (recommended)**, ready for
when auto-sync is explicitly enabled; importing does not enable it.
It contains no cloud credentials, billing entitlement, or active timers.
